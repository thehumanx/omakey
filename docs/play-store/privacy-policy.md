# omakey Privacy Policy

_Last updated: 2026-11-06_

omakey is a keyboard, so it can see what you type. This policy states what it does with that.

**Nothing you type leaves your device.** omakey has no servers, no accounts, no analytics, no
crash reporting and no advertising SDKs.

## What is stored on your device
- Words the keyboard learns for suggestions and autocorrect (your personal dictionary).
- Clipboard history, if you leave it on. Items apps mark as sensitive are never saved, nothing is
  saved in incognito mode or in password fields, and you can review, clear or switch it off in
  Settings → Privacy & data.
- Your settings, themes and layout choices.

This data stays in omakey's private app storage. It is not backed up to the cloud
(`allowBackup` is off) and is removed when you uninstall the app.

## Network use
The Play Store version uses the network for one thing only: downloading optional language packs
when you tap "Get more languages" and pick one. The request goes to omakey's public release files
on GitHub (github.com/thehumanx/omakey). Packs contain data only (layouts, word lists, a language
model), and are verified against a signed index before install. No typed text or personal data is
sent. As with any web request, GitHub can see your IP address under its own privacy policy.

## Permissions
- **Internet**: language pack downloads (above).
- **Vibrate**: key-press haptic feedback.

## Children
omakey does not knowingly collect any data from anyone, including children.

## Changes
Changes will be posted here and in the app's release notes.
